# Permission grant — Mark McDougall (PACE)

**Status:** transcript of the e-mail exchange; original message (with headers) archived
by the maintainer.

**Context:** Maintainer asked Mark McDougall by e-mail for
permission to use the PACE TRS-80 Model 1 code as a basis for this project, released
under MIT with attribution. The request read, in the operative part:

> Concretely: would you be willing to license the PACE TRS-80 code (or the project as a
> whole) under MIT, or otherwise permit its use as a basis for a project released under
> MIT? Attribution would be explicit — in the source, in the documentation, and in the
> project's credits.

**Reply (Mark McDougall):**

> That project was more of a "proof of concept" for a subsequent project I was planning
> but never got off the ground […] The HDL architecture itself was a "first pass" attempt
> at a MAME-like foundation for developing FPGA cores. […]
>
> Regardless, **feel free to use it as you will. I'm not overly attached to any of it
> anymore.** […]
>
> Good luck with it; **some credit somewhere in the source would be appreciated!**

**Interpretation applied by this project:** permission granted to use PACE TRS-80 code as
a basis for an MIT-released project ("otherwise permit" branch of the request), condition
treated as binding: credit in source, documentation, and CREDITS.md. Third-party
components inside PACE (e.g. T80, BSD) retain their own licenses and are checked per
file.
